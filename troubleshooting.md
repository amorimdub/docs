# Troubleshooting

## My AI Client cannot see a file

- Check that the file is a Company File or the Member's own Personal File.
- Verify the MCP Connection is linked to the right Workspace.
- Confirm the file format is supported for reading.

## A Procedure refuses to run

- Make sure every Required Input is satisfied.
- Check for Missing Requirements reported by the Procedure Authoring Tool.
- Confirm the Procedure has been published by an Owner.

## An Integration is not returning data

- Verify the Integration is connected for the correct scope.
- Check that the Integration Secret is still valid.
- Review whether the data is exposed as scoped text rather than embedded files.

## I see an AI-Actionable Error

AI-Actionable Errors explain what went wrong and what to do next. Follow the `next` guidance in the error response. For operation-specific errors, see the [AI-Actionable Error Catalog](/build-with-companyos/error-catalog).
